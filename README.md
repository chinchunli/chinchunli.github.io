# AI 面試系統功能模組概述

本文件整理了一套 AI 面試系統的三大功能模組與可能使用的技術堆疊、以及粗估開發成本，協助評估專案規模與資源需求。

## 1. 資料填寫模組
- **目的**：收集候選人資料與履歷，作為後續面試與分析的基礎。
- **前端呈現**：可透過網頁或行動 App 形式提供互動式表單。
- **基本驗證**：包含必填欄位檢查、格式校驗（如 Email、電話、檔案格式等）。
- **資料庫儲存**：依系統規模與需求，能搭配 MySQL、PostgreSQL，或 NoSQL 解決方案儲存表單結果。
- **預估成本**：約新台幣 20–50 萬（依 UI/UX 精緻度、欄位複雜度與整合需求調整）。

## 2. AI 視訊面試模組
- **視訊串流整合**：採用 WebRTC 或第三方 SDK（如 Agora、Twilio、Zoom API）達成即時視訊與錄影能力。
- **語音轉文字（ASR）**：支援多語言，常見服務包含 Azure Speech、Google Speech-to-Text、OpenAI Whisper 等。
- **AI 對話引擎**：基於大型語言模型（LLM）設計 Prompt 與評分邏輯，實現面試互動與智慧回應。
- **面試問題生成與即時分析**：運用自然語言處理（NLP）與情緒分析技術，對候選人的回答進行即時洞察。

## 3. 面試報告與決策建議模組
- **分數評估模型**：可從規則制起步，逐步加入機器學習模型，以量化候選人表現。
- **報告生成**：產出摘要、個人化回饋，並保留錄音錄影檔案以供追溯。
- **管理後台**：提供 HR 查閱、下載報告，設定評分規則與權限管理。

---

透過上述模組化設計，可將面試前、中、後的流程進行數位化與自動化，打造兼具效率與一致性的 AI 面試體驗。
